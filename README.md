# alarm-clock 
1:PROJECT DISCREPTION
    alarm clock programme using python
    By making this I understand the various libarary of python.
    we use it as a break time reminder!
    In the program user give the input in the form of:HH:MM:SS AM/PM
    After taking user input it will compare it with the exact time.
    If exact time is equal to the time which is given by user it give a message to user: time to take a break! and beep sound 4 times.
2:What I Used:
        Python
        datetime
        time
        winsound
How the Program Works:
1-First, the program asks the user to enter the alarm time.
    For example:08:45:00 AM
2-Then it takes the current time from the computer and compares it with the alarm time.
3-If the time matches, it prints:time to take a break!
4-After that, the alarm beeps 5 times.
5-Main Things Used in the Code
            datetime – to get the current time.
            time – to wait for one second before checking again.
            winsound – to make the beep sound.
            while loop – to keep checking the time.
            if condition – to check whether the alarm time has been reached.

What I Learned

While making this project, I learned how to take input from the user, work with time in Python, use loops and conditions, and make a sound using the winsound module.
